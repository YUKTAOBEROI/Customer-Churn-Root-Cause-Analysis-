# 📊 Customer Churn Analysis

## 📌 1. Project Overview

This project presents an end-to-end **Telecom Customer Churn Analysis** using SQL and Power BI. SQL was used for data cleaning, transformation, and analysis, while Power BI was used to build an interactive dashboard to visualize customer churn patterns, customer behavior, and key business metrics. The project helps identify the factors contributing to customer attrition and supports data-driven decision-making for improving customer retention.

---

## 🎯 2. Problem Statement

The objective of this project is to analyze customer churn in a telecom business by identifying the key factors influencing customer attrition and providing actionable insights to improve customer retention and reduce revenue loss.

---

## 💡 6. Key Insights

- Customers with month-to-month contracts have the highest churn rate.
- Fiber optic users show higher churn rates.
- Customers with shorter tenure are more likely to churn.
- Payment methods and service usage significantly influence customer retention.
